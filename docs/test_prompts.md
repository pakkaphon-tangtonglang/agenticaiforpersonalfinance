# Prompt ทดสอบระบบใน Streamlit

คัดลอก prompt ด้านล่างไปวางใน chat เพื่อทดสอบแต่ละ feature

---

## 1. Tax Agent (ภาษี)

### พื้นฐาน — คำนวณภาษี
```
คำนวณภาษี เงินเดือน 50,000 บาท/เดือน
```

### มีค่าลดหย่อน
```
คำนวณภาษีปี 2026 เงินเดือนเดือนละ 80,000 บาท มีลูก 2 คน ซื้อ SSF 200,000 และประกันชีวิต 100,000
```

### Cross-Agent — ดึงข้อมูลพอร์ต
```
คำนวณภาษีของฉัน พร้อมดูว่าพอร์ตการลงทุนมีกำไรที่ต้องเสียภาษีไหม
```

### Cross-Agent — ดึงข้อมูลค่าใช้จ่าย
```
วิเคราะห์ภาษีปีนี้ ดูรายจ่ายด้วยว่ามีอะไรลดหย่อนได้บ้าง
```

### ถามความรู้ (RAG)
```
RMF กับ SSF ต่างกันยังไง ลดหย่อนได้เท่าไหร่
```

---

## 2. Expense Agent (ค่าใช้จ่าย)

### บันทึกรายจ่าย
```
จ่ายค่าอาหารกลางวัน 150 บาท
```

### บันทึกหลายรายการ
```
วันนี้จ่ายค่ากาแฟ 80 บาท ค่าเดินทาง BTS 120 บาท และค่าอาหารเย็น 350 บาท
```

### สรุปรายเดือน
```
สรุปรายจ่ายเดือนนี้
```

### ดูตามหมวด
```
เดือนนี้ใช้จ่ายหมวดอาหารไปเท่าไหร่
```

### Cross-Agent — เทียบกับเป้าหมาย
```
ดูค่าใช้จ่ายเดือนนี้เทียบกับเป้าหมายการออมของฉัน
```

### ถามความรู้ (RAG)
```
วิธีลดค่าใช้จ่ายรายเดือนมีอะไรบ้าง
```

---

## 3. Investment Agent (การลงทุน)

### เพิ่มหุ้น
```
เพิ่มหุ้น PTT.BK 100 หุ้น ราคา 35 บาท
```

### เพิ่มกองทุน
```
ซื้อกองทุน K-EQUITY 5,000 บาท ราคา NAV 20 บาท
```

### ดูพอร์ต
```
ดูพอร์ตของฉัน
```

### อัปเดตราคา
```
อัปเดตราคาพอร์ตล่าสุด
```

### ดูหุ้นตัวเดียว
```
ดูรายละเอียดหุ้น PTT.BK ในพอร์ตของฉัน
```

### ขอคำแนะนำการลงทุน
```
วิเคราะห์พอร์ตของฉันแล้วแนะนำว่าควรปรับยังไง
```

### Cross-Agent — ดึงข้อมูลภาษี
```
ดูพอร์ตของฉัน พร้อมเช็คว่ามีผลกระทบทางภาษีอะไรบ้าง
```

### ถามความรู้ (RAG)
```
DCA คืออะไร เหมาะกับการลงทุนแบบไหน
```

---

## 4. Planning Agent (วางแผนการเงิน)

### สร้างเป้าหมาย
```
อยากออมเงินฉุกเฉิน 100,000 บาท ภายในสิ้นปี 2026
```

### สร้างเป้าหมายหลายประเภท
```
สร้างเป้าหมายดาวน์บ้าน 1,000,000 บาท ภายใน 3 ปี priority สูง
```

### ดูเป้าหมายทั้งหมด
```
ดูเป้าหมายการเงินทั้งหมดของฉัน
```

### อัปเดตยอดออม
```
ออมเงินฉุกเฉินเพิ่ม 10,000 บาท
```

### คำนวณแผนออม
```
ถ้าอยากออมเงิน 500,000 บาท ภายใน 2 ปี ต้องออมเดือนละเท่าไหร่
```

### Cross-Agent — ดึงค่าใช้จ่าย + รายได้
```
ดูเป้าหมายของฉัน เทียบกับรายจ่ายและรายได้ว่าเป็นไปได้ไหม
```

### Cross-Agent — ดึงพอร์ต
```
วิเคราะห์เป้าหมายการเงินร่วมกับพอร์ตการลงทุน ช่วยทำ net worth ให้หน่อย
```

### ถามความรู้ (RAG)
```
กฎ 50/30/20 คืออะไร ใช้วางแผนการเงินยังไง
```

---

## 5. Recommendation Agent (คำแนะนำเชิงรุก)

### วิเคราะห์ทั้งหมด
```
วิเคราะห์การเงินทั้งหมดของฉัน แล้วให้คำแนะนำ
```

### ตรวจสุขภาพการเงิน
```
ตรวจสุขภาพการเงินของฉัน
```

### ขอคำแนะนำเฉพาะด้าน
```
ช่วยดูว่าการเงินของฉันมีจุดไหนต้องปรับปรุงบ้าง
```

### ถามความรู้ (RAG)
```
มีคำแนะนำอะไรบ้างสำหรับคนเริ่มต้นจัดการการเงิน
```

---

## 6. Multi-Agent Collaboration (ข้ามโดเมน)

### Tax + Investment
```
วิเคราะห์ภาษีพร้อมดูพอร์ตการลงทุน
```

### Planning + Expense + Income
```
วางแผนการเงิน ดูรายจ่ายและรายได้
```

### Expense + Goals
```
ดูค่าใช้จ่ายเทียบเป้าหมาย
```

### Planning + Portfolio + Income
```
สรุปสถานะการเงินทั้งหมด เป้าหมาย พอร์ต และรายได้
```

## 7. Scenario ทดสอบครบวงจร (ทำตามลำดับ)

ทำตาม step 1-8 เพื่อสร้างข้อมูลก่อน แล้วทดสอบ recommendation

### Step 1: บันทึกรายจ่าย
```
จ่ายค่าอาหาร 8,000 บาท ค่าเดินทาง 3,000 บาท ค่าของใช้ 2,000 บาท
```

### Step 2: เพิ่มหุ้น
```
เพิ่มหุ้น PTT.BK 200 หุ้น ราคา 35 บาท
```

### Step 3: เพิ่มกองทุน
```
ซื้อกองทุน K-EQUITY 10,000 บาท ราคา NAV 25 บาท
```

### Step 4: สร้างเป้าหมาย
```
อยากออมเงินฉุกเฉิน 100,000 บาท ภายในสิ้นปี 2026
```

### Step 5: อัปเดตยอดออม
```
ออมเงินฉุกเฉินได้แล้ว 15,000 บาท
```

### Step 6: วิเคราะห์ทั้งหมด
```
วิเคราะห์การเงินทั้งหมดของฉัน แล้วให้คำแนะนำ
```

### Step 7: ตรวจสุขภาพการเงิน
```
ตรวจสุขภาพการเงินของฉัน
```

### Step 8: Cross-Agent
```
วางแผนการเงิน ดูรายจ่ายและรายได้
```
