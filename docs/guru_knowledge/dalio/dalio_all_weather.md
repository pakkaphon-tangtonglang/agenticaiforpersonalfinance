# พอร์ต All Weather

## แนวคิด
Ray Dalio และ Bridgewater ออกแบบพอร์ต All Weather ให้ทำงานได้ดีพอสมควรในทุกสภาวะเศรษฐกิจ
โดยไม่ต้องทำนายว่าอนาคตจะเป็นแบบไหน
สินทรัพย์แต่ละประเภทตอบสนองต่อการเปลี่ยนแปลงของ "การเติบโตทางเศรษฐกิจ" และ "เงินเฟ้อ" ต่างกัน
จึงมีสี่สภาวะที่ต้องรับมือ:
1. เศรษฐกิจโตเกินคาด
2. เศรษฐกิจโตต่ำกว่าคาด
3. เงินเฟ้อสูงเกินคาด
4. เงินเฟ้อต่ำกว่าคาด

## การจัดสรรตามความเสี่ยง (Risk Parity)
แทนที่จะแบ่งเงินเท่ากัน ให้แบ่ง "ความเสี่ยง" ให้สมดุลระหว่างสภาวะต่างๆ
เพื่อไม่ให้พอร์ตพึ่งพาสภาวะใดสภาวะหนึ่งมากเกินไป เช่น พอร์ตที่มีหุ้นเป็นหลักจะเสียหายหนักเมื่อเศรษฐกิจถดถอย

## จอกศักดิ์สิทธิ์ของการลงทุน
Dalio เรียกการกระจายการลงทุนในแหล่งผลตอบแทนที่ดีและไม่สัมพันธ์กันว่า "Holy Grail"
เพราะช่วยลดความเสี่ยงได้มากโดยไม่ลดผลตอบแทนที่คาดหวังมากนัก

## ข้อคิดนำไปใช้
- กระจายลงทุนในหลายสินทรัพย์ เช่น หุ้น พันธบัตร ทองคำ ไม่ใช่หุ้นอย่างเดียว
- ยอมรับว่าเราทำนายอนาคตไม่ได้ ให้พอร์ตทนได้หลายฉากทัศน์
- ปรับสมดุลพอร์ตเป็นระยะ
