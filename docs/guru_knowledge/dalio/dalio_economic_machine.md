# เศรษฐกิจทำงานอย่างไร

## สามแรงขับเคลื่อน
Dalio อธิบายว่าเศรษฐกิจขับเคลื่อนด้วยสามสิ่ง:
1. การเติบโตของผลิตภาพ (productivity) ในระยะยาว
2. วัฏจักรหนี้ระยะสั้น (ประมาณ 5-8 ปี) ซึ่งสัมพันธ์กับวัฏจักรเศรษฐกิจขาขึ้นขาลง
3. วัฏจักรหนี้ระยะยาว (ประมาณ 75-100 ปี) ที่หนี้สะสมจนต้องลดหนี้ครั้งใหญ่ (deleveraging)

## การใช้จ่ายของคนหนึ่งคือรายได้ของอีกคน
เมื่อทุกคนกู้เงินมาใช้จ่าย รายได้ของทุกคนก็เพิ่มขึ้นชั่วคราว
แต่เมื่อต้องจ่ายคืนหนี้ การใช้จ่ายและรายได้ก็ลดลงตาม

## กฎสามข้อสำหรับทุกคน
1. อย่าให้หนี้เพิ่มเร็วกว่ารายได้ เพราะภาระหนี้จะทับถมในที่สุด
2. อย่าให้รายได้เพิ่มเร็วกว่าผลิตภาพ เพราะจะทำให้แข่งขันไม่ได้
3. ทำทุกอย่างเพื่อเพิ่มผลิตภาพ เพราะเป็นสิ่งสำคัญที่สุดในระยะยาว

## ข้อคิดนำไปใช้
- ระวังการก่อหนี้ที่โตเร็วกว่ารายได้ โดยเฉพาะหนี้เพื่อการบริโภค
- พัฒนาทักษะตัวเองเพื่อเพิ่มรายได้อย่างยั่งยืน
