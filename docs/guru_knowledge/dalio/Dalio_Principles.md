# หลักการตัดสินใจของ Dalio

## Pain + Reflection = Progress
ความเจ็บปวดจากความผิดพลาด ถ้านำมาไตร่ตรองอย่างจริงจัง จะกลายเป็นการพัฒนา
Dalio เล่าว่าความผิดพลาดครั้งใหญ่ในปี 1982 ที่ทำนายเศรษฐกิจผิดจนเกือบหมดตัว
สอนให้เขาถ่อมตัวและมองหาคนที่เห็นต่างเพื่อทดสอบความคิด

## กระบวนการ 5 ขั้น
1. ตั้งเป้าหมายให้ชัดเจน
2. ระบุปัญหาที่ขวางเป้าหมายและไม่ยอมทนกับมัน
3. วิเคราะห์หาสาเหตุที่แท้จริง
4. ออกแบบแผนแก้ไข
5. ลงมือทำตามแผนอย่างมีวินัย

## ความจริงอย่างถึงที่สุด (Radical Truth)
มองความเป็นจริงตามที่เป็น ไม่ใช่ตามที่อยากให้เป็น
และเขียนหลักการตัดสินใจไว้ชัดเจน เพื่อไม่ให้อารมณ์ชักนำ

## ข้อคิดนำไปใช้
- จดบันทึกการลงทุนที่ผิดพลาดและเหตุผลที่ตัดสินใจ แล้วทบทวน
- ตั้งกฎการลงทุนของตัวเองล่วงหน้า (เช่น สัดส่วนสินทรัพย์) ก่อนตลาดผันผวน
