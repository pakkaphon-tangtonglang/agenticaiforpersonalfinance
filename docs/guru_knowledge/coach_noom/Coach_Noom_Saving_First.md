# ออมก่อนใช้และรากฐานการเงิน

หมายเหตุ: เอกสารนี้เป็นการสรุปแนวคิดที่เผยแพร่ต่อสาธารณะ ไม่ใช่คำพูดตรงตามต้นฉบับ

## ออมก่อนใช้
เมื่อได้รับเงินเดือน ให้กันเงินออมไว้ก่อนทันที แล้วจึงใช้ส่วนที่เหลือ
ไม่ใช่ใช้ก่อนแล้วค่อยออมเงินที่เหลือ ซึ่งมักไม่เหลือ
เริ่มจากสัดส่วนที่ทำได้จริง แล้วค่อยๆ เพิ่มขึ้น

## ลำดับการสร้างรากฐาน
1. ทำบันทึกรายรับรายจ่ายให้รู้ว่าเงินไปไหน
2. สร้างเงินสำรองฉุกเฉิน โดยทั่วไปประมาณ 3-6 เท่าของค่าใช้จ่ายรายเดือน
3. จัดการหนี้ดอกเบี้ยสูง เช่น บัตรเครดิต บัตรกดเงินสด ให้หมดก่อน
4. ทำประกันเพื่อปกป้องความเสี่ยงที่ทำลายฐานะการเงินได้
5. เริ่มลงทุนระยะยาวอย่างสม่ำเสมอ

## ข้อคิดนำไปใช้
- ตั้งโอนเงินออมอัตโนมัติทุกวันเงินเดือนออก
- แยกบัญชีเงินออม เงินฉุกเฉิน และเงินใช้จ่ายออกจากกัน
