# การลงทุนแบบเน้นคุณค่าสไตล์ ดร.นิเวศน์

หมายเหตุ: เอกสารนี้เป็นการสรุปแนวคิดที่ ดร.นิเวศน์ เผยแพร่ต่อสาธารณะเป็นประจำ
ไม่ใช่คำพูดตรงตามต้นฉบับ

## ซื้อหุ้นคือซื้อธุรกิจ
ดร.นิเวศน์ ได้รับการยกย่องเป็นผู้บุกเบิกการลงทุนแบบเน้นคุณค่า (VI) ในตลาดหุ้นไทย
แนวคิดหลักคือมองหุ้นเป็นส่วนหนึ่งของธุรกิจ เลือกบริษัทที่แข็งแกร่ง มีความได้เปรียบในการแข่งขัน
และเติบโตได้ต่อเนื่อง แล้วถือไว้ระยะยาวเพื่อให้ผลตอบแทนทบต้นทำงาน

## หุ้นเติบโตระยะยาว
เน้นหาบริษัทที่มีโอกาสเติบโตเป็นสิบปี โดยดูแนวโน้มใหญ่ของสังคมไทย
เช่น การเปลี่ยนแปลงโครงสร้างประชากร สังคมผู้สูงอายุ พฤติกรรมผู้บริโภคที่เปลี่ยนไป
อุตสาหกรรมที่อยู่ฝั่งได้ประโยชน์จากแนวโน้มเหล่านี้มีโอกาสเติบโตมากกว่า

## ลงทุนในหุ้นเป็นหลักระยะยาว
ในระยะยาวหุ้นของบริษัทที่ดีมักให้ผลตอบแทนสูงกว่าเงินฝากหรือพันธบัตร
แต่ต้องอดทนกับความผันผวน และไม่ขายเพราะตื่นตระหนกตามข่าว

## ข้อคิดนำไปใช้
- ศึกษาธุรกิจให้เข้าใจก่อนซื้อ ไม่ซื้อตามกระแสหรือข่าวลือ
- คิดแบบเจ้าของกิจการที่ถือยาว ไม่ใช่นักเก็งกำไร
- ใช้ชีวิตเรียบง่าย มีเงินลงทุนต่อเนื่อง
