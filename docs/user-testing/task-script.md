# สคริปต์การทดสอบผู้ใช้ (User Testing Task Script)

ใช้คู่กับ `sus-questionnaire.md` และ `recruitment-checklist.md`
ทดสอบบนระบบเวอร์ชันที่ freeze แล้ว (Stage D ในแผนงาน) ที่
`https://personal-finance-ai-wcr0.onrender.com/`

- เวลาต่อคน: ประมาณ 20–25 นาที (ภารกิจ ~15 นาที, แบบสอบถาม ~5 นาที)
- ผู้ทดสอบใช้ **ข้อมูลสมมติ** เท่านั้น ห้ามกรอกข้อมูลการเงินจริง
- ก่อนเริ่ม: เปิด uptime ให้ระบบตื่นแล้ว (เปิด `/health` ก่อน 1 ครั้ง)
  และกด "รีเซ็ต" ไอดีผู้ใช้ เพื่อให้ผู้ทดสอบแต่ละคนเริ่มจากข้อมูลว่าง

## บทพูดก่อนเริ่ม (อ่านให้ผู้ทดสอบฟัง)

> วันนี้เราทดสอบ **ระบบ** ไม่ได้ทดสอบคุณ ไม่มีคำตอบถูกหรือผิด
> ระหว่างทำ ขอให้พูดสิ่งที่คิดออกมาดัง ๆ เช่น "กำลังหาปุ่ม…" หรือ "งงตรงนี้"
> ผมจะไม่ช่วยระหว่างทำภารกิจ ถ้าติดเกิน 2 นาทีบอกได้ว่าข้ามได้
> ระบบเป็น AI ให้ข้อมูลเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน

## ภารกิจ

ผู้สังเกตบันทึกในตารางท้ายไฟล์: สำเร็จ / สำเร็จแต่มีปัญหา / ไม่สำเร็จ,
เวลาที่ใช้ และจุดที่ติด

| # | ภารกิจ (อ่านให้ผู้ทดสอบฟัง) | ฟีเจอร์ที่ทดสอบ | เกณฑ์สำเร็จ |
|---|---|---|---|
| 1 | "ถามระบบว่า ถ้าเงินเดือน 30,000 บาท ต้องเสียภาษีปีละเท่าไร" | แชท + Tax Agent | ได้คำตอบเป็นตัวเลขภาษี |
| 2 | "ดูว่าคำตอบเมื่อกี้อ้างอิงข้อมูลมาจากไหน" | Citation pill + popover | เปิดการ์ดแหล่งที่มาได้ |
| 3 | "บันทึกว่าวันนี้จ่ายค่าอาหาร 120 บาท" | Expense Agent | ระบบยืนยันการบันทึก |
| 4 | "ดูภาพรวมรายรับรายจ่ายของเดือนนี้" | แดชบอร์ด | เปิดหน้าแดชบอร์ดและเห็นรายการจากข้อ 3 |
| 5 | "ถาม Warren Buffett ว่าตลาดหุ้นตกควรทำอย่างไร" | แท็บกูรู (คุยกับกูรู) | ได้คำตอบมุมมอง Buffett |
| 6 | "ถามกูรูทุกคนพร้อมกันด้วยคำถามเดียว แล้วดูตารางเปรียบเทียบ" | ถามทั้งวง + ตารางสรุป | เห็นตารางเปรียบเทียบที่อ่านได้ |
| 7 | "กลับไปเปิดแชทกูรูที่คุยไว้เมื่อกี้" | ประวัติแชทกูรูใน sidebar | เปิดแชทเดิมจาก sidebar ได้ |
| 8 | "ดูราคาหุ้น PTT และเพิ่มเข้ารายการติดตาม" | หน้าสินทรัพย์ + watchlist | PTT อยู่ในรายการติดตาม |
| 9 | (ถ้ามีเวลา) "อัปโหลดรูปสลิปตัวอย่างนี้เพื่อบันทึกรายจ่าย" | อัปโหลดสลิป (OCR) | เห็นรายการให้ตรวจก่อนบันทึก |
| 10 | "ในแดชบอร์ด แก้จำนวนเงินค่าอาหารจากข้อ 3 เป็น 150 บาท แล้วลบรายการนั้นทิ้ง" | ประวัติรายรับ-รายจ่าย (แก้ไข / ลบ / เลิกทำ) | ยอดใหม่แสดงถูก และรายการหายหลังกดลบ |

เตรียมไฟล์สลิปตัวอย่าง (ข้อมูลปลอม) ไว้ในเครื่องที่ใช้ทดสอบสำหรับข้อ 9

## หลังจบภารกิจ

1. ให้ทำแบบสอบถาม `sus-questionnaire.md` ทันที
2. ถามคำถามปลายเปิด 3 ข้อในแบบสอบถาม และจดคำพูดสำคัญ
3. ขอบคุณ และลบข้อมูลทดสอบ (กด "รีเซ็ต" ไอดี)
