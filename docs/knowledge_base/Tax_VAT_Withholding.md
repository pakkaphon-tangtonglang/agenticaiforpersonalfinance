# ภาษีหัก ณ ที่จ่าย และภาษีมูลค่าเพิ่ม (VAT)

## ภาษีหัก ณ ที่จ่าย (Withholding Tax)

### ภาษีหัก ณ ที่จ่ายคืออะไร?
เป็นภาษีที่ผู้จ่ายเงินได้ **หักไว้ก่อนจ่าย** แล้วนำส่งกรมสรรพากรแทนผู้รับเงิน เป็นการจ่ายภาษีล่วงหน้า ไม่ใช่ภาษีเพิ่มเติม

### อัตราภาษีหัก ณ ที่จ่ายตามประเภทเงินได้

| ประเภทเงินได้ | อัตราหัก | ตัวอย่าง |
|--------------|---------|---------|
| เงินเดือน/ค่าจ้าง 40(1) | ตามอัตราก้าวหน้า | พนักงานประจำ |
| ค่าจ้างทำของ/ค่าบริการ 40(2) | 3% | Freelancer, ที่ปรึกษา |
| ค่าลิขสิทธิ์ | 3% | นักเขียน, นักแต่งเพลง |
| ดอกเบี้ยเงินฝาก | 15% | ดอกเบี้ยออมทรัพย์, ฝากประจำ |
| เงินปันผล | 10% | เงินปันผลจากหุ้น, กองทุน |
| ค่าเช่าอสังหาริมทรัพย์ | 5% | ค่าเช่าบ้าน, คอนโด |
| ค่าโฆษณา | 2% | ค่าลงโฆษณา |
| ค่าขนส่ง | 1% | บริษัทขนส่ง, ส่งของ |
| ค่ารางวัล/ชิงโชค | 5% | รางวัลจากการแข่งขัน |

### หลักเกณฑ์การหัก
- หักเมื่อจ่ายเงินตั้งแต่ **1,000 บาทขึ้นไป** (ต่อครั้ง)
- ยกเว้น: เงินเดือน หักทุกครั้งที่จ่ายไม่ว่าจำนวนเท่าใด
- ผู้หัก: **นิติบุคคล** หรือ **บุคคลธรรมดา** ที่เป็นผู้จ่ายเงิน

### ใบ 50 ทวิ (หนังสือรับรองการหักภาษี ณ ที่จ่าย)
- ผู้จ่ายเงินต้องออกให้ผู้รับเงินทุกครั้งที่หักภาษี
- ใช้เป็นหลักฐานเครดิตภาษีตอนยื่นภาษีประจำปี
- ต้องเก็บรักษาไว้อย่างน้อย 5 ปี
- ข้อมูลในใบ 50 ทวิ: ชื่อผู้จ่าย, ชื่อผู้รับ, จำนวนเงินที่จ่าย, ภาษีที่หัก, วันที่

### การนำส่งกรมสรรพากร
- นำส่งภายใน **วันที่ 7 ของเดือนถัดไป** (กระดาษ)
- นำส่งภายใน **วันที่ 15 ของเดือนถัดไป** (ออนไลน์)
- ใช้แบบ **ภ.ง.ด.1** (เงินเดือน), **ภ.ง.ด.3** (บุคคลธรรมดา), **ภ.ง.ด.53** (นิติบุคคล)

## ภาษีมูลค่าเพิ่ม (VAT)

### VAT คืออะไร?
- ภาษีที่เก็บจากมูลค่าที่เพิ่มขึ้นในแต่ละขั้นตอนการผลิต/บริการ
- อัตราปัจจุบัน: **7%** (อัตราจริง 10% แต่ลดเหลือ 7% ตาม พ.ร.ฎ.)
- ผู้บริโภคเป็นผู้รับภาระสุดท้าย

### ใครต้องจดทะเบียน VAT?
- ผู้ประกอบการที่มีรายได้เกิน **1,800,000 บาทต่อปี**
- ต้องจดทะเบียนภายใน 30 วันหลังรายได้ถึงเกณฑ์

### กิจการที่ได้รับยกเว้น VAT
- การขายพืชผลทางการเกษตร
- การขายสัตว์ (มีชีวิตหรือเนื้อสด)
- การขายหนังสือพิมพ์ นิตยสาร ตำราเรียน
- บริการขนส่ง (ในประเทศ)
- บริการด้านการศึกษา
- บริการรักษาพยาบาล
- การให้เช่าอสังหาริมทรัพย์ (ที่อยู่อาศัย)

### การคำนวณ VAT
- **ภาษีขาย** = VAT ที่เรียกเก็บจากลูกค้า
- **ภาษีซื้อ** = VAT ที่จ่ายให้ผู้ขาย
- **ภาษีที่ต้องนำส่ง** = ภาษีขาย - ภาษีซื้อ
- ถ้าภาษีซื้อ > ภาษีขาย → ขอคืนหรือเครดิตเดือนถัดไป

### ใบกำกับภาษี (Tax Invoice)
- ผู้ประกอบการ VAT ต้องออกใบกำกับภาษีทุกครั้งที่ขาย/ให้บริการ
- ต้องระบุ: เลขประจำตัวผู้เสียภาษี, ชื่อ/ที่อยู่, รายการสินค้า, จำนวนเงิน, VAT

## ความสัมพันธ์ระหว่างภาษีหัก ณ ที่จ่าย กับ ภาษีประจำปี

### สำหรับมนุษย์เงินเดือน
1. นายจ้างหักภาษี ณ ที่จ่ายจากเงินเดือนทุกเดือน
2. สิ้นปี นายจ้างออกใบ 50 ทวิ แสดงรายได้รวมและภาษีที่หักไปทั้งปี
3. ยื่น ภ.ง.ด.91 พร้อมค่าลดหย่อน
4. คำนวณภาษีจริงที่ต้องจ่าย
5. ถ้าหักไปเกิน → **ได้คืนภาษี**
6. ถ้าหักไปน้อย → **จ่ายเพิ่ม**

### สำหรับ Freelancer
1. ลูกค้า (นิติบุคคล) หักภาษี ณ ที่จ่าย 3% ทุกครั้งที่จ่ายค่าจ้าง
2. รวบรวมใบ 50 ทวิ จากทุกลูกค้าตลอดปี
3. ยื่น ภ.ง.ด.90 พร้อมรายได้ทุกแหล่ง
4. ภาษีที่หักไปแล้ว → นำมาเป็น **เครดิตภาษี**
