# แนวทางการจัดทำงบประมาณส่วนบุคคล

## กฎ 50/30/20

กฎพื้นฐานในการจัดสรรรายได้:

- **50% สำหรับค่าใช้จ่ายจำเป็น**: ค่าที่พัก ค่าอาหาร ค่าเดินทาง ค่าสาธารณูปโภค ค่าประกัน ค่าผ่อนหนี้
- **30% สำหรับค่าใช้จ่ายไม่จำเป็น**: ความบันเทิง ท่องเที่ยว ช้อปปิ้ง ทานอาหารนอกบ้าน
- **20% สำหรับการออมและลงทุน**: เงินออม กองทุนเกษียณ การลงทุน ชำระหนี้เพิ่มเติม

## หมวดหมู่รายจ่ายหลัก

### ค่าใช้จ่ายคงที่ (Fixed Expenses)
- ค่าเช่า/ผ่อนบ้าน
- ค่าผ่อนรถ
- ค่าประกันภัย
- ค่าโทรศัพท์/อินเทอร์เน็ต
- ค่าสมาชิก (streaming, gym)

### ค่าใช้จ่ายผันแปร (Variable Expenses)
- ค่าอาหารและเครื่องดื่ม
- ค่าเดินทาง/น้ำมัน
- ค่าสาธารณูปโภค (น้ำ ไฟ)
- ค่าของใช้ส่วนตัว
- ค่ารักษาพยาบาล

### ค่าใช้จ่ายตามอัธยาศัย (Discretionary Expenses)
- ความบันเทิงและสันทนาการ
- ท่องเที่ยว
- ของขวัญและงานสังคม
- งานอดิเรก

## กองทุนฉุกเฉิน

ควรมีเงินสำรองฉุกเฉิน 3-6 เดือนของค่าใช้จ่ายจำเป็น:

- **พนักงานประจำ**: เก็บ 3-6 เดือน
- **ฟรีแลนซ์/ธุรกิจส่วนตัว**: เก็บ 6-12 เดือน
- **เก็บในบัญชีออมทรัพย์หรือกองทุนตลาดเงิน** ที่ถอนได้ทันที

## อัตราการออมที่แนะนำ

| อายุ | อัตราออมขั้นต่ำ | อัตราออมแนะนำ |
|------|-----------------|---------------|
| 20-30 ปี | 10% | 20-30% |
| 30-40 ปี | 15% | 25-35% |
| 40-50 ปี | 20% | 30-40% |
| 50+ ปี | 25% | 35-50% |

## เทคนิคลดรายจ่ายในบริบทไทย

1. **ทำอาหารเอง**: ประหยัดได้ 30-50% เทียบกับทานนอกบ้าน
2. **ใช้ระบบขนส่งสาธารณะ**: BTS/MRT/รถเมล์ ประหยัดกว่าขับรถส่วนตัว
3. **เปรียบเทียบราคา**: ใช้แอปเปรียบเทียบราคาก่อนซื้อ
4. **ลดค่าใช้จ่ายสมาชิก**: ทบทวนค่า subscription ที่ไม่จำเป็น
5. **วางแผนการซื้อของ**: ซื้อตามรายการ หลีกเลี่ยงการซื้อแบบหุนหันพลันแล่น
6. **ใช้โปรโมชั่นและส่วนลด**: แต่ซื้อเฉพาะของที่ต้องการจริงเท่านั้น

## หลักการบันทึกรายจ่าย

1. บันทึกทุกรายการทุกวัน
2. จัดหมวดหมู่ให้ชัดเจน
3. ทบทวนรายจ่ายทุกสัปดาห์
4. วิเคราะห์แนวโน้มทุกเดือน
5. ปรับงบประมาณตามความเหมาะสม
