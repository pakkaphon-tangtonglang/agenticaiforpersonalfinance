# การลงทุนในหุ้นไทย

## ตลาดหลักทรัพย์แห่งประเทศไทย (SET)

ตลาดหลักทรัพย์แห่งประเทศไทย (Stock Exchange of Thailand: SET) เป็นตลาดหลักทรัพย์แห่งชาติ ก่อตั้งเมื่อปี 2518 ปัจจุบันมีบริษัทจดทะเบียนมากกว่า 800 บริษัท

### ตลาด SET และ mai

- **SET**: ตลาดหลักสำหรับบริษัทขนาดใหญ่และกลาง
- **mai (Market for Alternative Investment)**: ตลาดสำหรับบริษัทขนาดเล็กและกลางที่มีศักยภาพเติบโต

## เวลาซื้อขาย

- **Morning Session**: 10:00 - 12:30 น.
- **Afternoon Session**: 14:30 - 16:30 น.
- **Pre-open**: 09:30 - 10:00 น. (จับคู่ราคาเปิด)
- **Pre-close**: 16:30 - 16:40 น. (จับคู่ราคาปิด)

วันทำการ: จันทร์ - ศุกร์ (ยกเว้นวันหยุดราชการ)

## การชำระราคาและส่งมอบ

ระบบ T+2 หมายถึงการซื้อขายจะถูกชำระราคาและส่งมอบหลักทรัพย์ในวันทำการที่ 2 หลังจากวันที่ทำรายการ

## สัญลักษณ์หุ้น

หุ้นไทยใช้รหัสตามที่ SET กำหนด เช่น PTT, KBANK, SCB, AOT เมื่อใช้ใน Yahoo Finance จะเติม `.BK` ต่อท้าย เช่น `PTT.BK`, `KBANK.BK`

## ค่าธรรมเนียมการซื้อขาย

- **ค่าคอมมิชชั่น (Brokerage Fee)**: 0.15% - 0.25% ของมูลค่าซื้อขาย (ขึ้นอยู่กับโบรกเกอร์)
- **ค่าธรรมเนียม SET**: 0.005%
- **ค่าธรรมเนียมกำกับดูแล (กลต.)**: 0.001%
- **VAT 7%**: คิดจากค่าคอมมิชชั่นและค่าธรรมเนียม

## ภาษีที่เกี่ยวข้อง

- **ภาษีเงินปันผล**: หัก ณ ที่จ่าย 10% (สามารถเลือกไม่นำไปรวมคำนวณภาษีเงินได้ หรือนำไปรวมแล้วขอเครดิตภาษีคืนได้)
- **ภาษีกำไรจากการขายหุ้น (Capital Gains Tax)**: บุคคลธรรมดาที่ขายหุ้นผ่านตลาดหลักทรัพย์ได้รับยกเว้นภาษี
- **ภาษีกำไรจากการขายนอกตลาด**: ต้องนำไปรวมคำนวณภาษีเงินได้

## ดัชนีสำคัญ

- **SET Index**: ดัชนีราคาหุ้นรวมของตลาด SET
- **SET50**: ดัชนี 50 หุ้นขนาดใหญ่ที่มีสภาพคล่องสูง
- **SET100**: ดัชนี 100 หุ้นขนาดใหญ่
- **mai Index**: ดัชนีตลาด mai
